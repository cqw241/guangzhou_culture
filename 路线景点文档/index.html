三、文档内容说明

每份 *-景点信息.md 的结构一致：

  1. 总览：当天主题与景点数量。
  2. 按天分节：每天先给出「路线顺序」，再按顺序逐个介绍景点。
  3. 单个景点条目：
    • 简介（一句话）
    • 地址、交通（最近地铁站/步行方式）、开放时间、参考评分
    • 百度百科 / 维基百科链接
    • 详细介绍（原文全文，含历史背景、过程、意义等）
    • 配图（直接嵌入文档，图片文件在同目录 图片/ 中）
  4. 附录：路线交通衔接：景点之间的骑行/驾车/地铁时间，来自原项目「交通方式备注」页。

文档中的图片使用相对路径，因此 请保持文件夹结构不变；只拷贝单个 .md 文件会导致图片无法显示。

五、资料来源与整理规则

  • 景点正文：各路线文件夹原 新旅游路径.html 内嵌的景点数据（名称、简介、地址、交通、开放时间、评分、详细介绍、百科链接）。
  • 景点分级：原网页字段 fishbone = 1 标为「精华景点」，其余为「拓展景点」。
  • 交通衔接：各路线原 交通方式备注.html（完整版）。
  • 格式处理：网页中的 <br> 换行转为 Markdown 段落，源文本中的 <1>~<5> 标记转为 ①②③④⑤；文字内容未作删改。

已知的源数据问题

  1. 原项目四个目录里的 建筑介绍（中/英）.html 内容完全相同，只介绍沙面岛与圣心大教堂，不是各路线专属资料，因此未纳入本资料包。
  2. 四个「交通方式备注」完整版页面都引用同一个圆周游记地图链接，疑为模板残留，本资料包未收录该链接。
  3. 红色路线的「交通方式备注精华版」实际是海上丝绸之路路线的内容，创新路线精华版的标题写成了「岭南文化旅游交通规划」；本资料包统一采用各路线完整版交通数据。
  4. 原数据中有 73 处图片路径失效（如 图片/.jpg、图片/精彩照片//1.jpg），已剔除；其中「黄埔古港」借用海上丝绸之路路线目录下的同景点图片补齐。

六、怎么打开

  • 最简单：双击根目录 index.html，用 Chrome / Edge 等浏览器打开，点击路线即可阅读。
  • 单条路线：直接双击路线文件夹里的 *-景点信息.html。
  • 编辑或二次加工：打开同名的 .md 文件（Typora、Obsidian、VS Code 均可）。
  • 整个文件夹可以打包压缩后直接发送；HTML、Markdown 与图片都使用相对路径，请保持目录结构不变。
