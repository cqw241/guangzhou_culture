# 数智读广州 · Discover Guangzhou

四个主题、61个原始文化节点、13个篇章、4个双语策展案例的移动优先交互原型。

## 快速启动

在仓库根目录：

```bash
python3 -m http.server 8000
```

浏览器打开 `http://localhost:8000/demo/`。

> 直接双击 HTML 文件可能因浏览器对 `file://` 的 CORS 限制无法读取 `data.json`。请使用本地 HTTP 服务或部署 GitHub Pages。将 Pages 来源设为部署此目录的静态工作流或相应根目录。

## 当前功能

- 四大文化主题与13个叙事篇章
- 61个文化节点，原始资料详解和来源链接
- 按主题浏览、全文关键词搜索、筛选和详情弹窗
- 黄花岗、白天鹅、陈家祠、十三行四个中英双语策展案例
- 中文/英文界面切换（注意：61个原始长文并非已全部翻译）
- 离线关键词检索问答与来源链接（**非在线 LLM**）
- 移动端底部导航、响应式排版

## 重要边界

文化节点的地址、年份、开放时间和介绍来自原仓库资料包，尚未经专家逐条核验；路线示意关系图不是地理地图，也不提供导航；配图须逐项审查版权许可。
